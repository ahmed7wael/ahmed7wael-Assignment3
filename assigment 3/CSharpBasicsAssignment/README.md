# C# Basics Assignment (.NET 10.0)

This repository contains the completed **CSharpBasicsAssignment** built with **.NET 10.0** and C#. It demonstrates fundamental C# concepts including type casting, value vs. reference types, variable scopes, operators, memory management visualization, and bitwise algorithm solutions.
